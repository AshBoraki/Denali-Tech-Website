What does Control4 Connect actually do?

Your Control4 system can still operate locally without a subscription. Connect adds the cloud features that matter when you are away, want deeper personalization, or need the system to keep improving over time.

Published August 17, 2026By Denali Tech Team9 min read
Short answer: Connect is not what makes a light switch work inside the house. It is the service layer for features such as remote app access, mobile notifications, voice integrations, Intercom Anywhere, homeowner personalization, cloud backups and access to ongoing software improvements. Exact features still depend on the hardware and system configuration.

The features homeowners notice most

Control4 lists a broad set of Connect benefits. These six tend to be the easiest to understand in day-to-day use.

1Control from away

Check the system and use supported controls through the Control4 app when you are not on the home network.

2Useful notifications

Receive configured alerts for events such as a water leak, an unlocked door or a garage door left open.

3Intercom Anywhere

See and speak with supported door stations, doorbells and touchscreens from a compatible mobile device.

4Voice and Apple integration

Enable supported Alexa, Google Assistant and Apple integrations for convenient control.

5Personalization

Use supported Routines or When >> Then tools to adjust selected scenes and automations without rebuilding the system.

6Updates and backups

Gain access to ongoing software and security updates, automatic system backups and system insights.

Connect or 4Sight: which name applies?

The installation date matters. Control4 says 4Sight is available only for systems installed before April 23, 2024. Systems installed after that date use Control4 Connect as the cloud-service path.

Current path

Control4 Connect

Connect is the current service for newer Control4 installations. It supports remote access and the evolving cloud feature set described on Control4's current services page.

  • Current subscription name
  • Cloud and app features depend on the system design
  • Subscription status can be reviewed through the Control4 account
Eligible earlier systems

4Sight

4Sight remains the service name for eligible Control4 systems installed before the cutoff date. It provides remote access and other supported cloud features for those systems.

  • Do not rename an eligible legacy account without checking it
  • Controller and software age still matter
  • An existing-system audit should come before promises

What remote access looks like

What Connect does—and does not—solve

Connect can add

  • Supported remote access outside the home
  • Cloud-enabled app features and integrations
  • Personalized notifications and selected scene tools
  • System backups, insights and access to updates
  • A path to request supported help through the app

Connect cannot repair

  • Weak Wi-Fi or an unstable home network
  • A failed controller, power supply or third-party device
  • Incorrect programming or undocumented wiring
  • Obsolete hardware that lacks feature compatibility
  • A service issue that requires physical work in the home

Before activating or renewing, check four things

1. Account

Confirm the correct homeowner email, system registration and subscription status.

2. Controller and OS

Identify the controller generation and current Control4 software version.

3. Feature compatibility

Verify the devices and integrations needed for app, intercom, voice or Apple features.

4. Network health

Make sure the controller has stable wired network access and dependable internet service.

Important service boundary

Connect is not the same as an onsite service plan

Control4 also offers separate Assist services, and independent integrators may offer their own support plans. A Connect subscription does not automatically include onsite labor, replacement hardware, cabling repairs or every programming request. Ask exactly what is included before assuming one plan covers everything.
